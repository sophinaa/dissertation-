# Dissertation roadmap

## Monday meeting decisions

- [ ] Agree the final research question and research contribution.
- [ ] Confirm whether the evaluation compares the complete experience or isolates a single feature.
- [ ] Choose the business product category and catalogue size.
- [ ] Agree an MVP focused on product discovery.
- [ ] Decide whether accounts, checkout and admin remain optional.
- [ ] Establish ethics requirements before recruiting participants.
- [ ] Agree participant recruitment, study size and accessibility evaluation.
- [ ] Set deadlines and the next deliverable.

## Proposed milestones

### 1. Scope and evidence
- [ ] Requirements discussion with the business.
- [ ] Literature review: recommendation systems, conversational commerce and HCI.
- [ ] Define realistic product-finding tasks and success measures.

### 2. Design and preparation
- [ ] Real catalogue schema and reliable source data.
- [ ] Low-fidelity wireframes and formative feedback.
- [ ] Evaluation protocol and consent/data-retention plan.
- [ ] Ethics approval where required.

### 3. Core implementation
- [ ] Product catalogue API and storage.
- [ ] Explainable preference-based recommendations.
- [ ] Catalogue retrieval and LLM integration.
- [ ] Unknown-answer handling and factuality test cases.
- [ ] Keyboard, screen reader, contrast and reduced-motion checks.

### 4. Evaluation and writing
- [ ] Pilot study and refine tasks.
- [ ] Run approved comparison with counterbalanced order if within-subjects.
- [ ] Measure task success, time, relevance, usability and satisfaction.
- [ ] Evaluate assistant factuality separately.
- [ ] Analyse limitations, business implications and future work.

## Proposed evaluation caveat

A comparison of conventional shopping against a combined personalised/AI experience cannot attribute effects to either feature independently. Agree the desired level of attribution with the supervisor before implementing the full study.
